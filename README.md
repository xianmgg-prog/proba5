# ERP MVP — Versión de Prueba
ERP web todo-en-uno con Streamlit + SQLite. Listo para Streamlit Cloud.

## Credenciales demo
- admin / admin
- ventas / ventas
- almacen / almacen
- contable / contable

## Instalación local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Desplegar en Streamlit Cloud
1. Subir a GitHub
2. Conectar repo en https://share.streamlit.io
3. Seleccionar app.py → Deploy
